# Hand-Gesture-Control
This is a programmed tool for controlling your mouse cursor using your hand as a tool. Python is used as the programming language. The more better quality camera, the more better results.

Required dependencies to install in terminal:
  1. mediapipe
  2. opencv-python
  3. python autogui

#Paste the "main.py" in your code editor and run. Make sure you have installed the dependencies.
